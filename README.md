# Kuğulu Park Rangers Web Sitesi

Yeni tasarım, gönderilen Fenerbahçe sitesi referansının bölüm/hiyerarşi mantığıyla; Kuğulu Park Rangers'ın siyah-turuncu kimliğiyle hazırlanmıştır.

## Çalıştırma
Klasörü VS Code ile açıp Live Server üzerinden `index.html` çalıştırılabilir.

## Yönetim
`admin.html` üzerinden kulüp bilgileri, haberler, fikstür, oyuncular ve başarılar düzenlenebilir. İlk sürüm localStorage kullanır; gerçek sunucu veritabanına geçiş için veri yapısı hazırdır.

## Assets
- `assets/logo/logo.png`
- `assets/players/*.png`
- `assets/news/*.png`
- `assets/sponsor/*`
- `assets/shop/*`

Aynı dosya adındaki görseli değiştirdiğinde ilgili görsel otomatik olarak yeni görselle gösterilir.
